# LIMS-USB на Raspberry Pi

Это руководство описывает установщик устройства LIMS-USB, разработанного для отдельного коммерческого продукта — ЛИМС на платформе ProjectDB. Устройство принимает файлы с прибора через виртуальный USB-накопитель и передаёт данные на указанный сервер ЛИМС.

Перед началом зарегистрируйте устройство и получите параметры подключения у администратора ЛИМС. Установщик подготавливает устройство; сам сервер ЛИМС устанавливается отдельно.

## Оборудование и операционная система

Для установки понадобятся:

| Компонент | Конфигурация |
| --- | --- |
| Целевая плата | Raspberry Pi Zero 2 W |
| Стенд подготовки карты | Raspberry Pi 4 Model B Rev 1.5 |
| Операционная система | Raspberry Pi OS Lite, Bookworm, 64-bit |
| Подключение к прибору | USB-соединение для передачи данных через порт USB OTG платы |
| Сеть | Доступ к серверу ЛИМС и загрузке установочных пакетов |
| Индикатор состояния | RGB-индикатор: GPIO 22 — красный, GPIO 17 — зелёный, GPIO 27 — синий. GPIO используются только для индикации состояния устройства. |

## Подготовка карты памяти

1. Откройте Raspberry Pi Imager и выберите Raspberry Pi Zero 2 W, образ Bookworm 64-bit Lite и нужную карту памяти.
2. Настройте учётную запись, сеть и региональные параметры. Включите SSH для подключения к устройству.
3. Запишите образ и дождитесь завершения проверки. Запись удалит содержимое выбранной карты.
4. Вставьте карту в устройство или подготовительный стенд и включите его.
5. Подключитесь по SSH. Подготовьте адрес сервера ЛИМС, имя устройства и пароль доступа устройства.

## Загрузка и запуск

Откройте оболочку root на Raspberry Pi:

```bash
sudo -i
```

Загрузите установщик:

```bash
curl -fLO https://raw.githubusercontent.com/pavel-elblaus/projectdb/master/dist/pdb-install-raspberrypi.sh
```

После успешной загрузки запустите его:

```bash
bash pdb-install-raspberrypi.sh
```

**Если при загрузке возникла ошибка `curl: command not found`:** установите curl следующей командой, затем повторите загрузку и запуск:

```bash
apt-get update && apt-get install -y curl
```

### Вопросы установщика

| Вопрос | Что ввести |
| --- | --- |
| Адрес сервера ЛИМС | Адрес сервера, например `https://lims.example.org` или `http://192.168.1.10`. Если указать только домен, будет добавлено `https://`. |
| Имя устройства | Имя, под которым устройство зарегистрировано в ЛИМС. Предлагается `LIMS-USB`; замените его в соответствии с регистрацией. |
| Пароль доступа устройства | Пароль, назначенный устройству. Ввод отображается на экране, чтобы вы могли проверить его. Пароля по умолчанию нет. |
| Начать установку? | Проверьте сервер и имя устройства, затем нажмите Enter или введите `y` для продолжения. Ответ `n` отменяет установку. |

В имени устройства допустимы латинские буквы, цифры, точки, подчёркивания и дефисы — не более 100 символов. Первый символ должен быть буквой или цифрой. Пароль устройства предназначен для подключения к ЛИМС, а не для учётной записи SSH или PostgreSQL.

## Ход установки и завершение

Индикация этапов и продолжение после **Ctrl+C** описаны в разделе «Ход установки, логи и повторный запуск» [основного руководства](../README.ru.md). Лог устройства сохраняется в `~/.projectdb/log/projectdb-pi-install.*.log`; точный путь выводится при запуске.

После успешной установки устройство **автоматически перезагружается**, а служба LIMS-USB запускается при каждой загрузке.

## Проверка после перезагрузки

На стенде Raspberry Pi 4 проверьте запуск службы и соединение с ЛИМС по индикатору. Для проверки передачи файлов выключите стенд, переставьте карту в **Raspberry Pi Zero 2 W** и подключите прибор к USB OTG. После записи файла прибором убедитесь, что результаты появились в ЛИМС.

Состояния индикатора:

| Индикатор | Значение |
| --- | --- |
| Не горит | Устройство выключено или служба передачи ещё не запущена. |
| Фиолетовый | Запускается служба и инициализируется приложение. |
| Синий | Подготавливается передача или устанавливается соединение с сервером ЛИМС. |
| Зелёный | Соединение установлено, устройство передаёт данные. Получение данных проверьте в ЛИМС. |
| Красный | Проблема с сетью или недоступен сервер ЛИМС. |

## Диагностика

В командах ниже замените `LIMS-USB` именем устройства, указанным при установке.

Проверить службу приложения:

```bash
sudo systemctl status pdb.LIMS-USB.service
```

Наблюдать за её сообщениями:

```bash
sudo tail -f /root/.projectdb/log/pdb.LIMS-USB.log
```

Посмотреть сообщения USB-скрипта:

```bash
sudo tail -n 100 /root/.projectdb/log/projectdb-usb.log
```

Открыть настройки Raspberry Pi, включая параметры сети:

```bash
sudo raspi-config
```

Выключить устройство перед извлечением карты памяти:

```bash
sudo poweroff
```

Устройство управляется через systemd. Команды ProjectDB, меняющие режим запуска или конфигурацию службы, заблокированы. Команда `projectdb start LIMS-USB` запускает уже настроенную службу. Для обновления платформы используйте `sudo npm install projectdb@latest -g`; библиотеку релиза `app.so`, если она размещена в `/opt/pdb/lib`, заменяйте отдельно при остановленной службе.

Не передавайте другим файл подключения и план восстановления: они содержат пароль доступа устройства. При обращении за помощью укажите этап с ошибкой и относящиеся к нему сообщения лога без данных доступа.
